# The Daily Grind (Inuinverse ARG)

> **⚠️ PROJECT STATUS: LIVE**
> This repository hosts the fictional employee portal and newsletter for the **Inuinverse** Alternate Reality Game (ARG).

## 🕵️‍♂️ About the Project
"The Daily Grind" serves as a narrative hub for the Inuinverse storyline. It simulates a corporate newsletter and employee intranet for various brands, companies, and characters within the game's universe.

**Live Site:** [https://the-daily-grind-eight.vercel.app](https://the-daily-grind-eight.vercel.app)

## 📖 Lore / Context
* **Setting:** The corporate underbelly of the Inuinverse.
* **Purpose:** Players discover hidden lore, "leaked" company memos, and character backstories through this interface.
* **Atmosphere:** Dystopian corporate satire / Mystery.

---

## 🛠️ Tech Stack
* **Framework:** Next.js / React
* **Styling:** CSS Modules / Tailwind
* **Deployment:** Vercel
* **CMS:** Firebase (Firestore) for dynamic article loading.
